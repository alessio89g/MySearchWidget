# Button outlines

The button catalog includes Circle/Square, Squircle, Flower, Clover, Leaf, Pebble, Scallop and Teardrop. Shapes are configured in **Appearance → Button N → Button**. Corner rounding is available for Circle/Square.

`ButtonOutlines.kt` stores normalized vector contours. Paths scale to the button rectangle, and cached paths are copied before transformation so different widget instances cannot change one another. Circle and Squircle are generated analytically by the renderer.

The picker and backup validator share the shape catalog. Size, position, proportions and stacking are configured in **Layout**, independently for each button. The gallery in `assets/screenshots/button-shapes.png` is generated by the Android renderer test.
